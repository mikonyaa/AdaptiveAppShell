# AdaptiveShellDemo

This application demonstrates the package in a realistic studio workspace.

Open `AdaptiveShellDemo.xcodeproj`, choose the `AdaptiveShellDemo` scheme, and run on an iPhone or iPad simulator.

Launch arguments used by the capture script:

- `--showcase`
- `--search`
- `--graphite`
- `--stone`
- `--inspector`
- `--profile`

The demo data is deterministic and does not require a network connection or account.

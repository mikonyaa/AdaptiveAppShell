# Screenshot Assets

These are actual iOS 26.5 Simulator captures of the 1.0.4 candidate, refreshed on 14 October 2026 using Xcode 27.0. The devices were owned, temporary iPhone 17 Pro and iPad Pro 13-inch (M5) simulators. Status-bar time/battery were set with Simulator's own override. App content and pixels were captured directly; no design mockups or generated imagery are included here.

- `iphone-classic.png`
- `iphone-graphite-search.png`
- `ipad-classic.png`
- `ipad-stone.png`
- `ipad-inspector.png`

Landscape interaction is covered by hosted tests. The local XCTest landscape attachment has a rotated/cropped framebuffer and is excluded from the current gallery. A new landscape image should be added only after its actual capture has been visually verified.

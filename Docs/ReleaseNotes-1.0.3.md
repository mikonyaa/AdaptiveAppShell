# AdaptiveAppShell 1.0.3

`1.0.3` is a public-API-safe quality release for navigation behavior, compatibility, and documentation.

- Adds deterministic coverage for invalid selection, compact/regular transitions, per-tab paths, deep-link replacement, and inspector state.
- Uses the native glass button style on iOS 26 and macOS 26 while retaining compiler, system-version, and Reduce Transparency fallbacks.
- Clarifies that `AdaptiveShellThemeID` identifies a built-in preset family in `1.x`.
- Replaces the broad restoration claim with an app-owned recipe built on the existing state API.
- Aligns package and demo version metadata with `1.0.3`.

No public API was added or removed.

# Contributing

Keep changes focused, platform-native, and reusable.

Before opening a pull request:

1. Run `swift test`.
2. Build `AdaptiveShellDemo` for a generic iOS Simulator.
3. Check compact and regular widths.
4. Check one accessibility text size.
5. Run SwiftLint.
6. Update documentation when public behavior changes.

Do not add feature services, global singletons, decorative gradients, or glass content cards to the package target.

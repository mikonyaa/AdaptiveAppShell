# Adaptive App Shell Mockups

These mockups define the approved visual target before SwiftUI implementation.

| File | Layout | Purpose |
| --- | --- | --- |
| `iphone-overview.png` | Compact iPhone | Bottom-tab shell and overview hierarchy |
| `iphone-search.png` | Compact iPhone | Dedicated search and filtering state |
| `ipad-workspace.png` | Regular iPad | Sidebar, content column, and contextual inspector |

The screens use the same studio-workspace example and the same navigation model. They intentionally avoid decorative gradients and excessive glass. Final screenshots will be replaced with simulator captures after implementation.
